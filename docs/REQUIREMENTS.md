# makuai(幕間)— 要件・コンセプト定義

> 2026-07-05 の構想セッションの内容を引き継ぐためのドキュメント。
> プロジェクト名「makuai」は仮称。

## 一言で

**エンタメ特化の同行者日程調整サービス。** 調整さんの代替だが、ビジネスの会議調整ではなく、観劇・ライブ・推し活などの「公演にみんなで行く」ための調整に特化する。

## 調整さんとの根本的な違い

| 観点 | 調整さん | makuai |
|---|---|---|
| 候補の単位 | 自由な日付・時間 | **公演スロット**(公演日・開演時間が最初から決まっている) |
| 問い | 「いつ空いてる?」 | 「この公演のどの回なら行ける?」 |
| 回答 | 毎回手で○×入力 | **アカウントの常設ルール+カレンダー取り込みで自動回答**(手動上書き可) |
| 管理 | URLがグループごとに散らばる | **自分宛ての調整をダッシュボードで一括確認・一括回答** |
| 確定後 | 手動でカレンダー登録 | **確定イベントを各自のカレンダーへ自動追加** |

## コア機能

### 1. 公演スロット型の候補
- イベント作成時、候補は「2026-08-01 昼公演 13:00」「同日 夜公演 18:00」のような日時固定のスロットとして登録する。
- 主催者が公演情報(タイトル、会場、スロット一覧)を入力してグループに共有。

### 2. 参加可能人数の可視化
- スロットごとに「5人中4人参加可能」が一目でわかる表示(ヒートマップ的)。
- **誰が○/×かは表示する**(同行者の把握は必要)。
- **理由は一切表示しない**(仕様として存在させない)。

### 3. アカウント常設の都合ルール
- 「平日 9:00-18:00 は仕事で不可」「22時以降は不可」のような繰り返しNGルールをアカウントに設定。
- 新しい調整が来るたびにルールで自動的に○×が埋まる。毎回の手入力を不要にする。

### 4. Googleカレンダー取り込み(読み取り)
- その日にたまたま入っている予定も考慮して自動回答する。
- **プライバシー最重要**:取り込むのは空き/埋まり(busy/free)の時間帯のみ。**予定のタイトル・内容・場所は取得すらしない**(Google Calendar FreeBusy API 相当のみを使う)。
- 他のメンバーには集計結果(○×)しか見えない。埋まっている理由・元の予定は本人以外に一切露出しない。

### 5. ダッシュボード(一括確認・一括回答)
- 自分が参加している全グループ・全調整を1画面で確認。
- 自動回答結果を確認して、必要なところだけ手動で上書き。

### 6. 確定とカレンダー出力
- イベント確定は**システム内で完結**(Googleに依存しない)。
- 確定後、参加者それぞれのカレンダー(Googleカレンダー等)へ自動追加。カレンダー連携はあくまで**出力先の1つ**であり必須ではない。

## プライバシー原則(確定事項)

1. 参加者の氏名と○×は公開(グループ内)。
2. NGの理由はいかなる形でも公開しない・保持しない。
3. カレンダー取り込みは free/busy のみ。イベントの中身をサーバーに持ち込まない。

## トーン

ビジネス調整ツール(Spir / TimeRex 系)ではなく、エンタメ・推し活寄りの体験にする。UI・文言・雰囲気もそちらに寄せる。
